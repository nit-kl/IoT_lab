## 0. 事前準備（初回のみ）

factory-replay とは別の仮想環境を作る（RDF 用のライブラリを入れるため）。

```powershell
cd factory-kg
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt      # rdflib, pyshacl, pyoxigraph, boto3[crt]
```

ターミナルを開くたびに `.\.venv\Scripts\Activate.ps1` で有効化する。

### 確認 1-7（任意・replay の環境があるとき）：replay の API から生成する

factory-replay の環境を作って CSV を流した状態で:

```powershell
python tools/generate_ttl.py --owner <owner>
python tools/validate.py
python tools/query.py queries/02-line-a-properties.rq
```

- 表示の `API の URL` が replay の Function URL（`https://xxxxxxxx.lambda-url.ap-northeast-1.on.aws/`）になること
- 02 の最新値の URL が replay の URL で始まること。その URL は factory-replay の CLI や Postman と同じ要領（SigV4 署名）で呼べる
- replay に CSV が取り込まれていない・空のときは、その旨のメッセージで止まる

## うまくいかないとき

| 症状 | 原因と対処 |
|---|---|
| `カタログにないものがあります` | CSV / API に、カタログ（`tools/generate_ttl.py` の `EQUIPMENT_TYPES` / `METRICS` / `UNITS`）にない設備・計測項目・単位がある。カタログに追記して再生成する（単位を追加したら `python tools/vocab.py` も） |
| `公式の定義にない IRI があります` | 手書きの TTL か生成した TTL に、標準語彙に存在しない語がある。綴りを直す（標準の更新で語がなくなった場合は `python tools/vocab.py --refresh` で取り直して確認） |
| `SHACL 検証: 違反 …` | 表示された対象とメッセージを見て、カタログか手書きの TTL を直して再生成する |
| `vocab.py` で取得に失敗する | ネットワーク・プロキシを確認する。取得できた分は `.cache/vocab/` に残る |
| `--owner` 指定で `replay の環境（xcp-factory-<owner>）に接続できません` | replay の環境がない（`Stack … does not exist`）か、aws login が切れている。`--csv` で生成するか、replay を作る・ログインし直す |
| `MissingDependencyException ... botocore[crt]` | `pip install -r requirements.txt` をやり直す |
